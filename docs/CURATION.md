# 诗库遴选与核对方法

本项目的运行诗库不是从现代网站批量抓取而来，而是从三种公版扫描书目中为每首诗选取两个见证，逐首转录和整理成 50 首唐诗精选。它是一份面向博客排版的“双见证核对精选”，不是学术权威校勘本。

## 遴选规则

- 体裁固定为五言绝句、七言绝句各 25 首。
- 先纳入博客原有的 8 首本地备用诗，再依 1933 年春明书店本《唐诗三百首》相应体裁目录的先后顺序补足。
- 同一作者在全库最多 4 首。五绝中的王维已达 4 首，因此七绝略去目录第 3 首王维《九月九日忆山东兄弟》；五绝略去目录第 5 首王维《杂诗》。
- 标题、作者归属、作品身份、正文或扫描定位仍有疑问的条目不得进入运行数据。

> 核对中发现：本项目指定的 1933 年春明书店本目录不收崔护《题都城南庄》，但它又是必须保留的博客备用诗。项目因此为这一首设置唯一例外：主见证改用同年 3 月出版、国家图书馆藏《本事詩》（文藝小叢書社本）印刷页 26-27，并继续用 1705 年《御定全唐詩》复核。证据不得把这项替代写成春明书店本收录。

《本事詩》作“人面祗今何處去”，《御定全唐詩》正文作“人面不知何處在”。运行数据为保留博客原有备用诗，逐字择取为“人面不知何處去”：第 3、4 字取 1705 本，第 7 字取 1933《本事詩》。三处选择均写入 `variants`；这是一句公开披露的合校文本，不宣称任何一个见证原样载有整句。

## 见证与页码口径

1. 49 首诗的主底本为国家图书馆藏、春明书店 1933 年印行《唐诗三百首》扫描。`scanPage` 使用 PDF 从 1 开始的页面序号，`printedFolio` 抄录页面上可见的印刷页码。《题都城南庄》因该本未收，唯一例外使用 1933 年 3 月《本事詩》扫描第 31-32 页（印刷页 26-27）。
2. 核对本为 1705 年《御定全唐诗》公版扫描。由于 Commons 将全书拆成多件 DJVU 文件，每个见证必须同时记录具体文件、DJVU 从 1 开始的扫描页及页面上可见的卷叶信息。正文跨页时，`scanPage` 记录严格递增的连续页范围（例如 `135-136`），不得只写首页。
3. 只有在两个见证中都目视确认题名、作者归属与四句正文后，条目才标记为 `verified`；单个见证的正文可以跨页。
4. 两见证与选定繁体正文的每一个逐字差异均写入 `variants`，位置格式为 `line-N-char-M`（从 1 开始）。繁体正文到运行时简体正文的字符映射写入 `normalizations`。
5. 扫描件没有现代标点；运行时的两联标点由 API 在序列化响应时添加，不属于见证正文。

## 许可与边界

本项目只使用 Wikimedia Commons 文件页标记为公版扫描的材料，但具体司法辖区的公版状态仍应由使用者自行核验；项目不再分发这些扫描文件。本项目独立完成的转录、结构化数据、异文和简繁记录以 CC0-1.0 贡献。发现无法解决的缺字、异文、作者归属或作品身份问题时，维护者应移除运行条目或让服务拒绝启动，而不是猜测补全。
